# demolaptop_logs

Session logs recorded on the **demo laptop** (Ubuntu 20.04, UR10 CB3 rig), committed
so they can be analyzed from another machine. Same formats as a live run's
`catch_logs/` (`catch.py --record` JSONL) and `robot_logs/sessions/` (`wrap_up_session()`
SSH pull), just moved here so they don't mix with the local machine's own
`catch_logs/`/`robot_logs/` folders (which the scripts still write to).

Covers sessions 2026-09-11 through 2026-10-16.
